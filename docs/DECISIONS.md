# Decision Log

## D-000 — 项目边界（冻结）

- 项目：November-raining/psa-lyric。
- 个人学习和本人车机侧载。
- Android 9、ARM64 车机。
- CarLife 只负责导航；车机 QQ 音乐、网易云等本地播放器继续负责音频。
- GitHub 作为网页会话与 Codex 的状态桥；网页侧做代码和 CI，项目所有者签名/安装，Codex 做 ADB 验证。

## D-001 — 技术栈（已确认）

**原生 Android Kotlin + 自定义 Canvas/View。**

md3Music 只作为 Apple 歌词视觉和运动行为标尺，不移植 Flutter/Dart 源码。

## D-002 — Launcher 显示形态（已确认）

回到车机默认 Launcher 时：
- 隐藏右侧全高主悬浮歌词卡片；
- 自动切换为**屏幕顶部/状态栏高度的细歌词 Overlay**；
- 形态参考 Lyrics-Companion 激活顶部/通知栏歌词时的直接可见效果；
- 不使用“只有下拉通知中心才能看到”的系统 Notification 文本作为主要歌词面。

## D-003 — 屏幕背景高斯模糊（已确认）

- 默认：封面高斯模糊。
- 高级模式：MediaProjection 低频屏幕捕获后高斯模糊。
- 默认关闭，需要用户一次系统录屏授权。
- 后续 ADB 验证重点：overlay 自捕获反馈、更新频率和功耗。

## D-004 — 拖动与跳转（已确认）

- 拖动歌词 = 浏览。
- 双击歌词行 = MediaController.TransportControls.seekTo()。
- 5 秒无操作自动回弹到当前行。
- 普通单击不改变进度。

## D-005 — 歌词来源（已确认）

优先级：
1. 本地歌词；
2. 网易云逐字 YRC / LRC；
3. QQ；
4. 酷狗；
5. 普通逐行歌词兜底。

播放器来源与歌词来源解耦。

## D-006 — 许可证（已确认）

**AGPL-3.0-only**。

目标代码独立实现；参考 GPL/AGPL 项目只用于学习公开行为、协议边界和视觉参数。

## D-007 — CarLife 默认几何（已确认）

第二段视频确认音乐卡片完整展开后与左侧导航近似同高。默认 1920×720 设计矩形冻结为：

`x=1373, y=10, width=535, height=700`

运行时按分辨率缩放，后续实车允许微调并保存。
