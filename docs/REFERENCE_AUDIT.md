## zuo-qirun/Lyrics-Companion

- 公开仓库，主分支 main。
- 许可证：GPL-3.0。
- 已确认的实现思路：
  - NotificationListenerService + MediaSessionManager 读媒体。
  - TYPE_APPLICATION_OVERLAY 主屏/副屏悬浮。
  - FLAG_NOT_TOUCHABLE 做触摸穿透。
  - UsageStats/旧运行任务接口探测前台 App，并有黑白名单/降级逻辑。
  - 多来源歌词、歌词缓存、偏移校准、本地 LRC/KRC。
  - 顶部歌词条与 foreground-service 通知歌词是不同概念。
- 本项目只学习这些结构和边界，不复制源码或 UI 资源。

## zzyoxml/md3Music

- 公开仓库，默认分支 rust-local-force。
- 许可证：AGPL-3.0。
- Apple Lyrics 模块为 Flutter/Dart。
- 已确认的重要运动/视觉参数和行为：
  - 当前行锚位默认 0.35。
  - 非当前行缩放默认 0.85。
  - 默认模糊强度 1.0。
  - 辉光默认开启，动态歌词色默认开启。
  - 级联错峰默认最大约 750ms、相邻步长约 60ms、衰减约 1/1.1。
  - 已播字上浮默认约 3px。
  - 用户滚动后约 5 秒自动回弹，松手带惯性。
  - 用户滚动时模糊淡出。
  - 对唱、平衡换行、翻译副行、逐字渲染、上下渐隐都属于目标视觉系统。
  - 上传截图给出的用户参数为 29px / 600 / 0.9×。
- 本项目将用 Android Canvas/自定义动画重新表达这些行为；不拷贝 AGPL 源文件、类结构或资源。
